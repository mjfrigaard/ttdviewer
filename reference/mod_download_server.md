# Data Download Server Module

Data Download Server Module

## Usage

``` r
mod_download_server(id, data, title)
```

## Arguments

- id:

  Module ID

- data:

  Reactive named list of data frames from
  [`load_tt_data()`](https://mjfrigaard.github.io/ttdviewer/reference/load_tt_data.md)

- title:

  Reactive dataset title
